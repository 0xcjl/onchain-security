# Wallet and On-chain Self-Protection Checklist

| Item | What it is | How to detect | Suggested responsible role |
|---|---|---|---|
| Signature phishing and blind signing | `eth_sign`, hard-to-read non-EIP-712 messages, `permit`/`permit2`, `setApprovalForAll` may authorize assets or NFTs | Decode before signing and verify domain, chain, contract, spender, amount, nonce and expiry; refuse to sign if you cannot understand it; check approvals after signing | Trading agent (decode/block before trading); research agent (explain the risk); intelligence agent (track phishing cases) |
| Unlimited approvals and revocation | Unlimited `approve` or long-lived approvals let a spender keep moving assets | Check on-chain allowance/operator and spender; approve exact amounts only; review periodically and revoke via trusted official tools | On-chain data agent (scan alerts); trading agent (exact amounts); research agent (report approval risk) |
| Address poisoning | Attackers send small transactions from look-alike addresses to trick you into copying the wrong recipient | Compare the full address against a trusted source every time; verify chain, ENS/labels and transaction history; do not rely on the first and last characters | On-chain data agent (compare/alert); trading agent (recipient address re-check) |
| EIP-7702 delegation | An EOA can delegate to code; a malicious authorization can let delegated code operate the account's assets | Decode the authorization signature and delegation target; verify delegated code, chain and authorization scope; check the account's current delegation and revoke unrecognized ones | Research agent (analyze delegation target); trading agent (block before signing); on-chain data agent (scan for changes) |
| Owner / Authority changes | A contract admin, Tron account permission or Solana account owner is replaced, which can change control | Compare against official announcements and permission history; monitor changes to owner/admin, Tron active/owner permissions, Solana program owner/authority | On-chain data agent (change alerts); research agent (assess impact); intelligence agent (verify official announcements) |
| Frontend / DNS hijacking | DNS resolution, web code or third-party scripts are replaced so the wallet faces a fake transaction | Independently verify the official domain; stop immediately on certificate errors; check that contracts/parameters shown by the frontend match on-chain sources; watch for official stop-use announcements | Intelligence agent (incidents and stop-use flags); research agent (verify frontend and contracts); trading agent (verify transaction target) |
| Fake meeting software / malware | Counterfeit Zoom or similar meeting links/installers can steal screen, clipboard, sessions or keys | Do not install from DMs or search ads; verify domain and signature via official sources; review installers and permissions; refuse remote control and requests for seed phrases | Intelligence agent (phishing campaigns); installation manager agent (review installers/Skills); research agent (project security notices) |
| Safe multisig / Multisend / delegatecall | A malicious frontend or batch can smuggle approvals, transfers or arbitrary calls into one Safe transaction | Parse each target, function, parameter, asset diff and `delegatecall`; verify Safe threshold, signers and the official transaction builder | Trading agent (pre-execution parsing and diff check); research agent (audit the transaction plan); on-chain data agent (anomalous transaction alerts) |
| Private key / seed phrase hygiene | Plaintext storage, screenshots, cloud sync, clipboard or infected devices leak secrets | Never enter/store them in chats, web pages, screenshots, cloud drives or shared password vaults; back up offline and confirm the device is malware-free; migrate assets immediately on suspected leakage | Installation manager agent (security baseline); content publishing agent (education, never collect keys); research agent (team process review) |
| Supply chain | Wallets, browser extensions, SDKs, dependencies or update channels are poisoned | Verify publisher, signature, hash, exact version, lockfile, install hooks and dependency changes; update only after review | Installation manager agent (install gate); research agent (dependency/release checks); intelligence agent (security advisories) |

When any bot finds HIGH / REJECT, a major data gap, or an official stop-use warning, pause related transactions and escalate to a human per [gate-rules.md](gate-rules.md).
