# 钱包与链上自保清单

| 项目 | 是什么 | 如何检测 | 建议负责角色 |
|---|---|---|---|
| 签名钓鱼与盲签 | `eth_sign`、EIP-712 以外难读消息、`permit`/`permit2`、`setApprovalForAll` 可能授权资产或 NFT | 签名前解码并核对域名、链、合约、spender、额度、nonce 和有效期；无法理解就拒签；检查签后授权 | 交易代理（交易前解码/拦截）；研究代理（说明风险）；情报代理（追踪钓鱼案例） |
| 无限授权与撤销 | 无限 `approve` 或长期授权让 spender 可持续转走资产 | 检查链上 allowance/operator 与 spender；只授精确额度；定期复核并通过可信官方工具撤销 | 链上数据代理（扫描提示）；交易代理（精确额度）；研究代理（报告授权风险） |
| 地址投毒 | 攻击者发送相似地址的小额交易，诱导复制错误收款地址 | 每次比对完整地址与可信来源；核对链、ENS/标签和交易记录，不凭首尾字符 | 链上数据代理（比较/告警）；交易代理（收款地址复核） |
| EIP-7702 委托 | EOA 可委托代码；恶意授权可能让委托代码代为操作账户资产 | 解码授权签名和委托目标；核对委托代码、链与授权范围；检查账户当前委托并撤销不认识的委托 | 研究代理（分析委托目标）；交易代理（签名前拦截）；链上数据代理（扫描变化） |
| Owner / Authority 变更 | 合约管理员、Tron 账户权限或 Solana 账户 owner 被替换，可改变控制权 | 对照官方公告及历史权限；监控 owner/admin、Tron active/owner 权限、Solana program owner/authority 的变更 | 链上数据代理（变更告警）；研究代理（评估影响）；情报代理（核对官方公告） |
| 前端 / DNS 劫持 | 域名解析、网页代码或第三方脚本被替换，钱包面对假交易 | 独立核对官方域名；证书错误立即停止；核对前端显示的合约/参数与链上来源；关注官方停用公告 | 情报代理（事件与停用标记）；研究代理（核对前端与合约）；交易代理（验证交易目标） |
| 假会议软件 / 恶意软件 | 仿冒 Zoom 等会议链接/安装包可窃屏、剪贴板、会话或密钥 | 不从私信/搜索广告安装；经官方来源核对域名和签名；审查安装包及权限；拒绝远程控制和索要助记词 | 情报代理（钓鱼活动）；安装管理代理（审查安装包/Skill）；研究代理（项目方安全提醒） |
| Safe 多签 / Multisend / delegatecall | 恶意前端或批处理可在一笔 Safe 交易中夹带授权、转账或任意调用 | 逐项解析交易目标、函数、参数、资产差异和 `delegatecall`；核对 Safe 门限、签名者及官方交易构造器 | 交易代理（执行前解析与差异核对）；研究代理（审计交易方案）；链上数据代理（异常交易告警） |
| 私钥 / 助记词卫生 | 明文存储、截图、云同步、剪贴板或受感染设备会泄密 | 不在聊天、网页、截图、云盘或共享密码库输入/保存；离线备份并确认设备无恶意软件；疑似泄露立即迁移资产 | 安装管理代理（安全基线）；内容发布代理（传播教育，不收集密钥）；研究代理（团队流程审查） |
| 供应链 | 钱包、浏览器插件、SDK、依赖或更新通道被投毒 | 核验发布者、签名、hash、精确版本、lockfile、安装钩子和依赖变更；审查后再更新 | 安装管理代理（安装闸门）；研究代理（依赖/发布核查）；情报代理（安全公告） |

任何机器人发现 HIGH / REJECT、重大数据缺失或官方停用警告时，按 [gate-rules.md](gate-rules.md) 暂停相关交易并升级给人类。
